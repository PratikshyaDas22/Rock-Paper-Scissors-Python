# Rock-Paper-Scissors-Python
A simple Rock Paper Scissors game made with Python.

## About the Project

This is a simple Rock Paper Scissors game I made while learning Python. The computer randomly chooses one option, and the player enters their choice. The program then compares both choices and shows whether the result is a win, loss, or draw.

## How It Works

I used numbers to represent Rock, Paper, and Scissors:

- `1` = Rock
- `-1` = Paper
- `0` = Scissors

I used dictionaries to connect the user's input (`r`, `p`, or `s`) with these numbers and to display the choices as words.

The `random` module is used to let the computer choose randomly. Then, `if` and `elif` conditions compare the two choices and decide the result.

## Concepts I Used

- User input
- Variables
- Dictionaries
- `random` module
- `if`, `elif`, and `else`
- f-strings

## What I Learned

While making this project, I learned how to take input from a user, use dictionaries to store and convert values, generate a random choice, and use conditions to control the result of a program.
